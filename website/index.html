常见问题

你可能关心的问题

JobAgent 安全吗？我的简历会泄露吗？

JobAgent 默认本地运行，简历、Cookie、投递记录和生成文件都存在本机 SQLite 与目录中，不强制上传云端。API Key 通过环境变量配置。

需要哪些平台账号？

BOSS直聘、猎聘、智联需要对应的登录态；腾讯、网易、比亚迪、北方华创、长飞光纤等公开职位源无需单独账号。

适合应届生吗？还是只适合有经验的人？

都适合。JobAgent 根据你的实际简历与目标岗位进行匹配和定制，应届生和有经验求职者都可以使用。

可以做成私有化部署吗？

可以。企业和团队版支持本地/私有化部署咨询、招聘源按需接入、定制开发与系统集成。

除了界面，能自动化运行吗？

可以。内置 17 个 CLI 命令，支持搜索、匹配、材料生成、投递追踪、模拟面试、定时任务等自动化操作。
